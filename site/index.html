Robot actions in 267 ms on a laptop.

An inference engine for Apple Silicon. Language, vision and action models on the GPU and the Neural Engine, measured against PyTorch, MLX and llama.cpp.

See the numbers Source

Same model, a third of the time

Every stage of SmolVLA runs on the Neural Engine through Core ML. The vision towers are 70% of what is left, and attention inside them is the part nothing has made faster yet.

Benchmarks

Median of three interleaved rounds per configuration, one process each, on an idle machine plugged in. The baselines run their fastest setting on the same machine.

Where it loses

3.41 vs 4.58

ms per token, SmolVLM decode against MLX. The gap sits inside llama.cpp's Metal decode path, which runs the engine's text model.

212 vs 164

tokens per second at 4-bit, MLX-LM against llama.cpp's Q4_K_M. The engine inherits llama.cpp's number.

15x

more error in the SmolVLA action chunk on the Neural Engine (1.2e-2) than on the GPU (7.5e-4). The speed costs precision.

What moved the numbers

Each change was measured before and after, one at a time. One of these made things worse, and one was a measurement error.

    Use it from Python, C++ or a terminal

    # pip install dooms-0.2.0-py3-none-macosx_11_0_arm64.whl
import dooms

llm = dooms.LLM("qwen2.5-0.5b-instruct-q4_k_m.gguf")
print(llm.chat([{"role": "user", "content": "Name three colours."}], max_new_tokens=48))

for piece in llm.stream("Once upon a time", 200, temperature=0.8, seed=1):
    print(piece, end="", flush=True)

vla = dooms.VLA.from_dir("models/smolvla")
actions = vla.infer([cam1, cam2, cam3], "pick up the red cube", state)
    // find_package(dooms 0.2 REQUIRED)  target_link_libraries(app PRIVATE dooms::dooms)
#include <dooms/dooms.hpp>

dooms::Llm llm("qwen2.5-0.5b-instruct-q4_k_m.gguf");
std::string answer = llm.chat({{"user", "Name three colours."}}, 48);

llm.generate("Once upon a time", 200, {0.8f, 40, 0.95f, 1.0f, 1}, {"\n\n"},
             [](const std::string & piece) { std::cout << piece; return true; });
    dooms-cli llm --model qwen2.5-0.5b-instruct-q4_k_m.gguf \
              --prompt "Name three colours." --max-tokens 64 --stats

dooms-cli vlm --image photo.jpg --prompt "Describe this image." --models models/smolvlm

dooms-cli vla --models models/smolvla --prompt "pick up the cube" \
              --camera a.jpg --camera b.jpg --camera c.jpg --state 0,0,0,0,0,0
    Any GGUF
    Every architecture and quantization llama.cpp loads, with chat templates, streaming, stop strings and seeded sampling.
    Self-contained
    The wheel and the SDK carry their own libraries. No build tree, no Xcode project.
    Apple Silicon only
    Metal on the GPU, Core ML for the Neural Engine, Accelerate on the CPU.
    Apache-2.0
    The engine and bindings. Models keep their own licences and are never bundled.
